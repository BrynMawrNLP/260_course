## Overview

In this homework you will implement a Naive Bayes classifier for categorical
data and investigate how a protected attribute can be encoded in other

consider what this reveals about the limits of simply removing protected

- implement Naive Bayes for binary and multiclass classification;
- use Laplace smoothing and log probabilities;
- evaluate a classifier against simple baselines; and
- explain redundant encoding and interpret balanced error rate.

### Model and smoothing

Naive Bayes assumes that the features are conditionally independent given
the class. For each candidate class `k`, its score is proportional to:

```text
P(y = k) × product over features j of P(x_j | y = k)
```

Let `n` be the number of training examples, `K` the number of classes,
`N_k` the number of training examples in class `k`, and `N_k,j,v` the number
of training examples in class `k` whose feature `j` has value `v`. Let
`|F_j|` be the number of possible values of feature `j`.

Use add-one Laplace smoothing for both priors and likelihoods:

```text
P(y = k)           = (N_k + 1) / (n + K)
P(x_j = v | y = k) = (N_k,j,v + 1) / (N_k + |F_j|)
```

Include every possible value of each feature, even when its count within a
particular class is zero.

### Train in log space

Compute and store all model probabilities in the constructor, using natural
logarithms. Do not recount training examples or recompute probabilities each
time you classify a test example.

Store the log priors in `log_class[k]`. Store likelihoods in
`log_feature[feature_name][feature_value][k]`, a nested dictionary whose
innermost values are lists indexed by class. These named attributes allow
individual training calculations to be tested independently.

Taking a logarithm turns a ratio into a difference of **logarithms**:

```text
log P(y = k)           = log(N_k + 1) - log(n + K)
log P(x_j = v | y = k) = log(N_k,j,v + 1) - log(N_k + |F_j|)
```

For the original census training data, the smoothed log priors should be
approximately:

```python
[-0.39003307271614496, -1.1302097192251246]
```
