## Overview

An 8 × 8 image contains 64 pixel values, but those values are not independent:
neighboring pixels and recurring shapes give the data structure. Principal
component analysis (PCA) uses that structure to describe observations with fewer
coordinates. The central question in this assignment is what those coordinates
preserve, and what we lose when we discard the rest.

You will connect the eigenvalues and eigenvectors from class to a PCA
implementation using singular value decomposition (SVD). Then you will use your
implementation to explore handwritten digits: how many components capture most
of their variation, what a two-dimensional view reveals, and how recognizable
the images remain after reconstruction. A final, shorter experiment uses SVD
on a single image to make the tradeoff between quality and storage visible.

## Part 1: Implement PCA using SVD (30 points)

### From observations to principal coordinates

Throughout the PCA implementation, each row of $$X$$ is an observation and each
column is a feature. Thus $$X$$ has shape $$(n,p)$$ for $$n$$ observations with
$$p$$ features. PCA describes variation around the feature means, so the first
step is to subtract the **column means**:

$$X_c=X-\mu.$$

This is also why the fitting mean must be saved: later observations need to be
expressed relative to the same origin. Centering each new batch around its own
mean would change the coordinate system.

The reduced SVD provides the directions and the amount of variation along
them:

```python
U, s, Vt = np.linalg.svd(X_centered, full_matrices=False)
```

With $$r=\min(n,p)$$, the returned shapes are $$U:(n,r)$$, $$s:(r,)$$,
and $$V^T:(r,p)$$. NumPy orders the singular values from largest to smallest;
the corresponding **rows of `Vt`** are the principal directions. See the
[NumPy SVD documentation](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)
for the return-value conventions.

Keeping the first $$k$$ directions gives a matrix $$W_k=V^T[:k]$$ of shape
$$(k,p)$$. An observation then has $$k$$ principal coordinates instead of $$p$$
original features. Projection and reconstruction are:

$$Z=(X-\mu)W_k^T,\qquad \widehat X=ZW_k+\mu.$$

Reconstruction returns to the original feature space, but discarded components
are no longer available. The result is generally an approximation of the
original observation.

The connection to covariance appears in the sample variances:

$$\lambda_j=\frac{s_j^2}{n-1},\qquad
q_j=\frac{s_j^2}{\sum_{\ell=1}^{r}s_\ell^2}.$$

Here $$\lambda_j$$ is the covariance eigenvalue associated with direction
$$j$$, and $$q_j$$ is its fraction of the total variance. The denominator uses
**all** singular values, even when the model keeps only $$k$$ components:
we want the fraction of the original variation that survives the reduction.

### The PCA class

The three methods separate learning a coordinate system from using it:

```python
class PCA:
    def __init__(self, n_components: int) -> None:
        ...

    def fit(self, X: np.ndarray) -> "PCA":
        ...

    def transform(self, X: np.ndarray) -> np.ndarray:
        ...

    def reconstruct_data(self, Z: np.ndarray) -> np.ndarray:
        ...
```

`fit()` learns from $$X$$, stores the following attributes, and returns `self`.
A later call to `fit()` replaces that fitted state.

| Attribute | Shape | Meaning |
|---|---|---|
| `mean_` | `(p,)` | Feature means of the fitting data |
| `components_` | `(k, p)` | Retained principal directions, one per row |
| `singular_values_` | `(k,)` | Singular values for the retained directions |
| `explained_variance_` | `(k,)` | Sample variances along those directions |
| `explained_variance_ratio_` | `(k,)` | Fractions of total variance explained |

`transform()` maps an array of shape `(m, p)` to coordinates of shape `(m, k)`
using the **stored fitting mean and directions**. `reconstruct_data()` maps
coordinates of shape `(m, k)` back to observations of shape `(m, p)`, adding
the fitting mean. None of these methods should modify its input array.

Our reconstruction method uses the terminology from class. Scikit-learn calls
the corresponding method `inverse_transform()`, which you will use for its
model in Part 2.

Inputs are real numeric NumPy arrays, and `n_components` is a Python `int`;
support for lists, strings, complex arrays, or arbitrary object conversion is
outside the assignment. The supplied validation requires finite 2D fitting
data with at least two rows, one column, nonzero total centered variance, and
`1 <= n_components <= min(n, p)`. It raises `ValueError` for invalid dimensions,
nonfinite values, invalid component counts, or incompatible transformation
shapes, and `RuntimeError` for a transformation before fitting. Keep these
provided checks in place while completing the calculations.

### Checking the geometry

A useful implementation check tests a mathematical property rather than just
one expected output. Complete `numerical_checks()` in `run_pca.py` with
executable checks of these three properties:

- Principal directions are orthonormal:
  `components_ @ components_.T` is approximately the identity.
- Keeping all available components reconstructs the fitting data.
- Increasing `k` cannot increase total squared fitting reconstruction error,
  apart from roundoff.

Use approximate comparisons such as `np.allclose`; exact floating-point
equality is not appropriate here. Include these checks in your submitted code.

## Part 3: Low-rank image approximation (20 points)

In the digits experiment, one row of the data matrix represents a whole image
and one column represents a pixel feature. SVD can also be applied directly
to a **single image matrix**, whose rows and columns are spatial positions.
This short experiment uses the same decomposition in a different setting,
so pay attention to what the matrix represents.

The driver in `run_svd.py` loads the provided 128 × 128 grayscale image with
`load_svd_image()` and computes its reduced SVD **without centering**. It reuses
that decomposition at several ranks. Complete
`low_rank_approximation(U, s, Vt, k)` to combine the first $$k$$ terms:

$$A_k=U_{:,:k}\Sigma_kV^T_{:k,:},\qquad
\Sigma_k=\operatorname{diag}(s_{:k}).$$

Broadcasting is fine in place of constructing the diagonal matrix. Once the
function is complete, the driver saves the original and approximations for
`k = 1, 2, 5, 10` together in `figures/svd_image.pdf`, using a common grayscale
range of 0–1. This comparison figure is worth **10 points**.

The remaining **10 points** are for one short paragraph in `README.md`.
Compare the meanings of rows and columns in the digits PCA matrix and this
single-image matrix, and explain why uncentered image approximation is a
different task from fitting PCA across images. Then describe the visible

Support your choice with the counts: an $$m\times p$$ image stores $$mp$$
